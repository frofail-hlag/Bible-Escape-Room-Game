Bibelreise V3.5.5 — Explicit Readable JSON Reminder

Current release summary
- Guided prompts support German, Arabic, and English; the prompt follows the selected language.
- All student-facing activity content must remain bilingual in German and Arabic.
- Escape Room puzzles and Bibel-Challenge questions offer 3, 4, 6, 7, or 10 items (default: 4).
- Adds the direct, concise quality-rule instruction “Write it in a readable JSON format” in the selected prompt language, before the more detailed JSON formatting rules. This wording mirrors the teacher's successful test.
- Detailed instructions continue to require readable two-space indentation, straight ASCII double quotes, complete arrays, valid values for every key, no trailing commas, no Markdown fences, and a final syntax check.
- Imported content is validated and previewed before it can be saved as a draft; activities are never automatically published.
- Bibel-Challenge validation, student-result serialization, and Firestore rules support up to 10 questions and corresponding answers.
- No direct AI/API request or OpenAI API key is used.

Deployment note
GitHub Pages must deploy the updated files. The service-worker cache has been bumped to V3.5.5 so installed PWAs can retrieve the revised prompt.
